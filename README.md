# 4SF25CI015_3B
Milestone 1 – Data Analysis Using Python

Project Overview

This project analyzes the Superstore Sales dataset using Python and Pandas.

Objectives

- Read and understand CSV data.
- Perform data transformation.
- Identify and handle missing values using mean imputation.
- Generate meaningful insights.
- Visualize data using graphs.

Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

Dataset

Superstore Sales Dataset containing information about sales, profit, products, customers and regions.

Analysis Performed

1. Dataset reading and understanding.
2. Data transformation.
3. Null value identification and handling.
4. Sales and profit analysis.
5. Region-wise and category-wise analysis.
6. Data visualization.

Conclusion

The project demonstrates data cleaning, transformation, analysis and visualization using Python libraries.
